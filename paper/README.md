# Manuscript

`paper.tex` is the manuscript for this work. It is kept here so it is version
controlled and backed up alongside the code and results it reports; it was
previously a single uncommitted file in a home directory.

## Building

No LaTeX toolchain is installed on the training machine, so the PDF is built
elsewhere (Overleaf, or any TeX Live install). Figures are not stored in this
directory — each is an output of the analysis that produced it and already lives
under `results/`, so a second copy here would go stale the next time one is
regenerated. Collect them first:

```bash
bash paper/collect_figures.sh   # from the repository root
cd paper && xelatex paper.tex && bibtex paper && xelatex paper.tex && xelatex paper.tex
```

The document uses XeTeX (`l3backend-xetex` appears in the build log of the
released PDF); `pdflatex` has not been tested.

For Overleaf, run `collect_figures.sh` and upload `paper.tex` together with the
`figures/` directory it creates.

## What is not committed

`paper/figures/` (assembled, see above) and the LaTeX build products
(`*.aux`, `*.log`, `*.out`, `*.bbl`, `*.xdv`, `paper.pdf`). The PDF is
regenerable from the source and is a 1.9 MB binary that changes on every
compile, so it is left out — this repository has already had to be rewritten
once to remove 24 GB of committed binaries.
